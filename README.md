## 还原方法

1. 把三个仓库 clone 到**同一个父目录**，保持目录名为 mhls1 / mhls2 / mhls3。
2. 在任一仓库目录执行：`python restore.py [输出目录]`（默认输出到父目录下的 `restored/`）。
3. 脚本会按 `MANIFEST.json` 顺序合并分片，并逐片、逐文件校验 SHA256。

## 说明

- `parts/` 下每个 `.partNNN` 分片均小于 50 MB，符合 GitHub 推荐体积。
- `MANIFEST.json` 是全局清单，三个仓库各存一份，内容相同。
- 分片本身不可直接使用，必须先还原。
- 本仓库为公开归档，请勿在其中放置任何凭据、令牌或未授权内容。
